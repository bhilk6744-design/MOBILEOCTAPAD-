# Mobile Octapad

Phone-friendly GitHub Actions build. Upload this project's files to a GitHub repository (not the ZIP itself), then Actions -> Build APK -> Run workflow. The resulting artifact contains `app-debug.apk`.

Features: 8 pads, audio sample loading, per-pad tuning, -10..-1/+1..+10 quick tune buttons, pitch slider, volume, patch name, local save/load.
